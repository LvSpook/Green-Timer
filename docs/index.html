A tiny, always-on-top timer overlay

Count up, count down, run a Pomodoro, or count to a specific time — over any window, without stealing clicks. Frameless, transparent, and built in Rust.

Work in progress

Green Timer is actively in development. Builds are published as pre-releases, and the UI, settings and file formats may still change between versions. Expect rough edges.

Features

Everything the overlay can do, without opening a manual.

⏱️ Timer modes

  • Count Up — plain stopwatch
  • Countdown — with optional looping on zero
  • Clock — wall clock with a custom format
  • Pomodoro — work / break / long break cycles
  • Interval (HIIT) — work, rest and rounds
  • Target Time — count down to 17:00

🎨 Display styles

  • Text — plain numbers
  • Arc — circular progress ring
  • Bar — horizontal progress bar
  • Fluid — wavy liquid fill
  • Sprite — image revealed by progress

✨ Look and feel

  • 7 built-in themes plus a custom theme builder
  • Colours, fonts, opacity, padding, corner radius
  • Gradient fills, text shadows, warning pulses
  • Optional Windows blur / acrylic backdrop
  • Rotation that carries the background and assets with it

⚙️ Behaviour

  • Global hotkeys, matched by physical scan code
  • System tray with quick actions
  • Customisable right-click menu
  • Saved profiles and per-app auto-switch
  • Auto-pause when a target app loses focus
  • Lap history with CSV export

Build from source

Requires a Rust toolchain (1.80 or newer).

Run the app

cargo run --release

Build the installer (Inno Setup required for the setup EXE) 

powershell -ExecutionPolicy Bypass -File build.ps1

Run the tests

cargo test

Settings locations

Saved per user, so the app works when installed under Program Files.

ItemPath
Settings%APPDATA%\GreenTimer\timer_pro_settings.json
Logs%APPDATA%\GreenTimer\logs\green_timer.log
